OpenCLAW 跨部门协作系统 · 架构图

主-分架构 · MQ 解耦 · 模型路由 · 成果共享 · V1.0

连接方式

  • 分节点 Agent 主动连接主节点 NATS
  • WebSocket 长连接，内网/VPN 接入
  • 心跳 30s 上报，健康检测
  • 主节点不下行主动连接，零暴露端口

任务分配与并发

  • 全局优先级队列 + 部门独立队列
  • 分节点按权重（并发能力）拉取任务
  • 分节点自控 max_concurrency 硬上限
  • 失败自动重试 3 次 → 死信队列

降本增效关键

  • 模型自动路由：简单任务走本地小模型
  • 复杂推理按需调 API，按量付费
  • 成果一键分享，减少重复造轮子
  • 闲置节点自动降频，忙时弹性扩容
