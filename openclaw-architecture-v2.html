OpenCLAW 跨部门协作系统 · 终版架构图

NATS JetStream · 4C8G 云服务器 · 三级模型路由 · 全链路可观测 · V2.0

任务流转

  • 创建任务 → NATS 任务队列
  • 员工手动领取（30min 超时释放）
  • 10min 自动兜底分配
  • Agent 执行 → 进度上报 → 成果提交
  • 死信队列：重试 3 次失败入人工

模型选择（三级）

  • 1级: 自动路由 → 最便宜模型
  • 2级: 员工手动覆盖 → 成本对比
  • 3级: 管理员锁定 → 部门级配额
  • 结果缓存: SHA256 复合 Key
  • 降级链: 超阈值自动降级

运维保障

  • 心跳 → Redis TTL 60s，状态变更 → PG
  • 领取超时 30min + 任务回收 2h
  • 幂等性: 领取/提交/进度三接口
  • 灰度 10% 先跑一周
  • Prometheus 全链路可观测
